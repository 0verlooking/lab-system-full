## ✅ ЩО ЗРОБЛЕНО:

### Backend:
- ✅ **7 Domain Entities**: Group, Comment, LabWorkPhoto, EquipmentPreset, EquipmentOrder, Document, News
- ✅ **7 Repositories**: CRUD операції для всіх entities
- ✅ **4 Services**: Бізнес-логіка для Groups, Comments, Orders, News
- ✅ **4 Controllers**: REST API endpoints:
  - `/api/groups` - керування групами
  - `/api/comments` - коментарі до проектів
  - `/api/orders` - кошик/замовлення обладнання
  - `/api/news` - новини та оголошення
- ✅ **Оновлений User**: firstName, lastName, email, phone, studentId, group, curator, 2FA
- ✅ **CORS** налаштовано
- ✅ **API paths** виправлено
- ✅ **TypeScript** виправлено

### Доступні API Endpoints:

#### Групи:
- `GET /api/groups` - список груп
- `POST /api/groups` - створити (CURATOR/ADMIN)
- `PUT /api/groups/{id}` - оновити (CURATOR/ADMIN)
- `DELETE /api/groups/{id}` - видалити (ADMIN)

#### Коментарі:
- `GET /api/comments/labwork/{id}` - коментарі проекту
- `POST /api/comments` - додати коментар
- `PUT /api/comments/{id}` - редагувати
- `DELETE /api/comments/{id}` - видалити (soft delete)

#### Замовлення (Кошик):
- `GET /api/orders/my` - мої замовлення
- `GET /api/orders/pending` - на погодження (LABORANT/ADMIN)
- `POST /api/orders` - створити замовлення
- `POST /api/orders/{id}/reserve` - зарезервувати (24 год)
- `POST /api/orders/{id}/approve` - погодити (LABORANT/ADMIN)
- `POST /api/orders/{id}/reject` - відхилити (LABORANT/ADMIN)

#### Новини:
- `GET /api/news` - активні новини
- `POST /api/news` - створити (CURATOR/ADMIN)
- `POST /api/news/{id}/publish` - опублікувати (CURATOR/ADMIN)
