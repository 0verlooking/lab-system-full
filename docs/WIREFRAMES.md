## Навігація та UX потоки

### Головний навігаційний flow

```
┌──────────┐
│  Login   │
└────┬─────┘
     │
     ▼
┌──────────┐     ┌─────────────┐     ┌──────────────┐
│   Home   │────▶│ Repository  │────▶│ Project Detail│
└────┬─────┘     └─────────────┘     └──────────────┘
     │
     ├────────▶ ┌─────────────┐     ┌──────────────┐
     │          │  Catalog    │────▶│    Cart      │
     │          └─────────────┘     └──────┬───────┘
     │                                      │
     │                                      ▼
     │                                ┌──────────────┐
     │                                │   Orders     │
     │                                └──────────────┘
     │
     ├────────▶ ┌─────────────┐
     │          │   Admin     │
     │          └─────────────┘
     │
     └────────▶ ┌─────────────┐
                │   Profile   │
                └─────────────┘
```

### User Journey: Створення замовлення

1. **Каталог** → Перегляд обладнання
2. **Додавання в кошик** → Вибір потрібних пристроїв
3. **Кошик** → Перегляд, редагування кількості
4. **Оформлення** → Заповнення форми
5. **Підтвердження** → Відправка заявки
6. **Замовлення** → Відстеження статусу

### User Journey: Публікація проекту

1. **Репозиторій** → Огляд існуючих проектів
2. **Створення** → Форма нового проекту
3. **Вибір обладнання** → Прикріплення необхідних пристроїв
4. **Додавання фото** → Завантаження зображень
5. **Публікація** → Збереження та публікація
6. **Деталі** → Перегляд опублікованого проекту

## Адаптивний дизайн

### Breakpoints

```css
/* Desktop */
@media (min-width: 1024px) {
  .grid-cols-3 { grid-template-columns: repeat(3, 1fr); }
  .grid-cols-4 { grid-template-columns: repeat(4, 1fr); }
}

/* Tablet */
@media (max-width: 1023px) and (min-width: 768px) {
  .grid-cols-3 { grid-template-columns: repeat(2, 1fr); }
  .grid-cols-4 { grid-template-columns: repeat(2, 1fr); }
}

/* Mobile */
@media (max-width: 767px) {
  .grid-cols-3 { grid-template-columns: 1fr; }
  .grid-cols-4 { grid-template-columns: 1fr; }

  /* Sidebar стає внизу */
  .cart-layout { flex-direction: column; }
}
```

### Mobile адаптація

**Навбар:**
- Desktop: Горизонтальне меню
- Mobile: Hamburger menu

**Грід проектів:**
- Desktop: 3 колонки
- Tablet: 2 колонки
- Mobile: 1 колонка

**Форми:**
- Desktop: 2 колонки (grid-cols-2)
- Mobile: 1 колонка

**Кошик:**
- Desktop: 2 колонки (контент + sidebar)
- Mobile: Стек (sidebar внизу)

## Ключові UX принципи

### 1. Consistency (Послідовність)
- Єдина кольорова схема на всіх сторінках
- Однакові компоненти (кнопки, картки, форми)
- Стандартні іконки для однотипних дій

### 2. Feedback (Зворотний зв'язок)
- Hover ефекти на інтерактивних елементах
- Спінер при завантаженні
- Успішні повідомлення після дій
- Валідація форм у реальному часі

### 3. Affordance (Очевидність)
- Кнопки виглядають як кнопки
- Посилання підкреслені або виділені кольором
- Disabled стан для неактивних елементів
- Плейсхолдери в полях введення

### 4. Hierarchy (Ієрархія)
- Чіткі заголовки сторінок
- Розділення на секції з іконками
- Використання розмірів шрифтів для важливості
- Візуальні групи через картки

### 5. Accessibility (Доступність)
- Контрастні кольори тексту
- Alt-тексти для зображень (в prod)
- Keyboard navigation
- ARIA labels де потрібно

## Висновок

Дизайн системи побудований на принципах:
- **Простота** - зрозумілий інтерфейс без зайвих елементів
- **Консистентність** - єдина система компонентів
- **Адаптивність** - коректна робота на всіх пристроях
- **Доступність** - зручність для всіх користувачів

Всі wireframes реалізовані з використанням сучасних CSS технологій:
- CSS Grid для layout
- Flexbox для вирівнювання
- CSS Variables для теми
- CSS Transitions для анімацій
